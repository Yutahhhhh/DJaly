# DDJ-1000 PAD / RELEASE FX / ジョグ操作の修正

2026-09-09、ユーザー報告を受けた追補。アートワーク処理は変更していない。

## PAD切り替え

- `pad-state.ts` でデッキごとのモードとページを共有。画面だけに閉じたReact状態と一時イベントへの依存を解消。
- 公式表の8種類のモードNOTEを全デッキでフィードバックする。曲未ロードでもKEYBOARD / KEY SHIFTを含めて選択可能。
- 画面でモードを変えた場合は、実機がモード出力に反応しない場合にも受信パッドを選択した機能へルーティングする。ボタン解放は押したときの機能へ戻す。
- モード／ページ切り替えで古いNOTE OFFが来なくても、保持中のPAD FXを解除する。PAD FX 2も保持できるよう画面の解除条件を修正。
- SAMPLERをデッキ側の選択肢とパッドに追加。音源のロードは既存のSAMPLERパネルで行う。
- LEDと実際の本体モードの同期は実機での確認待ち。MIDIのページ出力に反応しないファームウェアがあるという[Mixxxの実機調査](https://github.com/mixxxdj/mixxx/wiki/ddj-1000)も考慮している。

## RELEASE FX / BEAT FX

- 従来の`fxRelease`は`enabled:false`を送るだけでリリース用の音声処理が存在しなかった。
- SHIFT + BEAT FX ON/OFF（94 43）の押下で一時的なRELEASE ECHO、解放で通常のエフェクト設定へ復帰しOFFにする。rekordbox全種類のRELEASE FX再現ではなくMixxxのECHOを用いた実装。
- LEVEL/DEPTHや選択変更は一時エフェクトを終了してから適用。遅れて届いたボタン解放が新しい設定を上書きしない。
- 切断時に保持を解除。旧ホストに対して無反応なコマンドを送らず、新しい`mixer.beatfx.release` capabilityがない場合は再起動が必要と表示。
- 未対応BEAT FXを通過するとONの意図まで失われていた。対応する種類に戻す際にON/OFF状態を復元する。未対応中のON/OFF操作も復帰後へ反映。

## ジョグ

- 再調整でアプリの初期感度を0.5から0.05 ms/countへ下げた。設定バージョン3への移行時に、既存の大きい保存値も0.05以下へ補正する。より細かい保存値は保持する。
- 調整範囲0.005〜0.25 ms/count、0.005刻み。標準値への復帰ボタンを用意。
- 0.05は暫定初期値。実機の一回転のカウント測定による校正値、rekordboxと同じ応答とは主張しない。音声エンジンのスクラッチ位置制御は変更していない。
- JOG FEELING ADJUSTは本体の回転抵抗。メーカーも[操作負荷の調整](https://www.pioneerdj.com/ja/product/dj-controllers/ddj-1000/)と説明している。提供された453件のMIDI表にその設定値の通知はなく、ソフトから重さを取得したり変更したりする実装は追加していない。

## 検証

### PAD表示・ページ・色の再修正

- デッキPADを横4列×縦2列に統一し、PAGE 1 / PAGE 2を直接選択可能にした。SAMPLERのBANKは既存の4バンクとして別扱い。
- HOT CUEはA–H / I–P、BEAT JUMPは共有プリセットの異なる8割り当てへ切り替える。KEYBOARD / KEY SHIFTも2ページに統一。
- 画面で選んだモードを本体のページキーでも維持し、PAGE 2を繰り返しても存在しないページへ進まない。
- 保存済みホットキュー色を画面とMIDI出力に渡す。PAD FXはエフェクト別の色を使用。MIDIの色番号は[MixxxのDDJパレット調査](https://github.com/mixxxdj/mixxx/wiki/Pioneer-Ddj-Controllers#ddj-pad-colors)に基づく。画面RGBと実LEDの色一致は未測定。
- モードメニューを画面内へ配置し、狭い画面では操作行を折り返して高さを確保。KEY / SLIP / MEMORYは開閉式にした。
- 追加修正後のNode回帰テスト111件成功。Playwrightによるコンポーネント画面操作で4×2配置、HOT CUE 2ページ目、BEAT JUMP 2ページ目、モード選択を確認。幅980 / 1280 / 1440pxでPAD領域の余剰スクロールなし。実機スクラッチ感とLED発色は未確認。

### 先行修正時の検証

- Node回帰テスト107件成功。8モードの未ロード時切り替え、LED選択、画面から実物PADのルーティング、モード変更後の解放、RELEASE FX再押下、未対応BEAT FX通過後の復帰、細かいジョグの往復を含む。
- ネイティブDDJ-1000統合テストとsamplerテスト成功。
- 録音テストでRELEASE ECHOの音声出力と、ノブ変更後の再発動を確認。テスト音源をMacBook Airのスピーカーへ出力し、エンジン内のマスターを録音した。DDJ-1000の実音／LEDを実機で確認したという意味ではない。
- フロントエンドとネイティブホストをビルド。新ホスト利用にはアプリ再起動が必要。
